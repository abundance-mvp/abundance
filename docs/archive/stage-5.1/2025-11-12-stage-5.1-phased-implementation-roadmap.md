## MVP Feature Breakdown (from ADR-003)

### P0: Core Cataloging Flow (Must-Have for Launch)

1. **Epic 1: Onboarding & Authentication**
   - User can sign in with Apple ID (Firebase Auth)
   - User sees welcome screens (3 screens: welcome, permissions, sign-in)
   - User grants camera permissions

2. **Epic 2: Camera Capture (Layer 1)**
   - User can open camera view
   - User sees real-time object detection overlays (bounding boxes, confidence)
   - User can capture photo with detected objects
   - User sees barcode detection indicator (if present)
   - Photos uploaded to Firebase Storage (cropped objects)

3. **Epic 3: AI Cataloging Pipeline (Layers 2-3)**
   - Backend processes captured photos automatically
   - Layer 2a extracts attributes (Gemini: category, color, material, condition)
   - Layer 2b searches for product info (SerpAPI + barcode lookup)
   - Layer 3 synthesizes final metadata (Claude Sonnet: conflicts, confidence, value)
   - Users see progressive updates (Layer 1 → 2a → 2b → 3)

4. **Epic 4: Catalog View**
   - User sees grid of cataloged items (2 columns iPhone, 3-4 iPad)
   - User can tap item to view details
   - User can search catalog
   - User sees empty state (friendly copy)

5. **Epic 5: Item Detail & Edit**
   - User sees full item metadata (photo, name, category, brand, value, etc.)
   - User can edit any field
   - User can delete item
   - Edits saved to Firestore

### P1: Essential Polish (Launch Blockers)

6. **Epic 6: Accessibility & Localization**
   - Reduce Transparency fallback (opaque backgrounds)
   - Reduce Motion fallback (cross-fade transitions)
   - VoiceOver labels on all interactive elements
   - Dynamic Type support (cap at xxxLarge)

7. **Epic 7: Error Handling & Offline**
   - Network error handling (retry, offline queue)
   - Failed item processing UI (show failed items, manual retry)
   - Loading states (skeletons, progress indicators)

### P2: Nice-to-Have (Post-Launch)

8. **Epic 8: Data Export**
   - User can export catalog (CSV, JSON, PDF formats)
   - Export button in Profile view
   - Share Sheet integration (UIActivityViewController)

9. **Epic 9: Profile & Settings**
   - User sees subscription status (free tier, premium tier)
   - User can manage preferences (notifications, theme)
   - User can view privacy policy, terms of service

10. **Epic 10: Analytics & Monitoring**
    - Firebase Analytics tracking (screen views, button taps, errors)
    - Cloud Logging for backend errors
    - Cloud Monitoring dashboards (API latency, error rates)

            ├─> processLayer2aAttributes (Backend)
