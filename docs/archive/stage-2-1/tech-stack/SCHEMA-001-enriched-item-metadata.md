# SCHEMA-001: Enriched Item Metadata Structure

**Document ID:** SCHEMA-001
**Date:** 2025-10-29 (Original), 2025-11-01 (Stage 2.1 Update)
**Status:** ACCEPTED
**Related:** ADR-015 (AI Reasoning Layer), ADR-016 (SerpAPI Integration), ADR-017 (Claude Haiku Parsing), DESIGN-005 (Four-Layer Pipeline), PRD-001 (Abundance MVP)

---

## Purpose

This document defines the structured JSON schema for item metadata generated by the four-layer AI enrichment pipeline (Layer 1: YOLOv3-Tiny + Layer 2a: Gemini 2.5 Flash-Lite + Layer 2b: SerpAPI + Claude Haiku 4.5 + Layer 3: Claude Sonnet 4.5).

**Goals:**

- Standardize metadata format across all catalog items
- Support rich search/filtering (condition, color, material, category)
- Track data provenance (which layer generated each field)
- Enable confidence scoring for validation
- Support actions (save, request_photo, manual_review)

---

## Layer Metadata Contributions

### **Layer 1: Object Detection (YOLOv3-Tiny)**

Fields populated by on-device object detection:

| Field | Type | Description |
|-------|------|-------------|
| item_id | string | Generated unique identifier |
| created_at | timestamp | When object was detected |
| photos | array | Original and cropped image references |

### **Layer 2a: Vision Analysis (Gemini 2.5 Flash-Lite)**

Fields populated by vision-based attribute extraction:

| Field | Type | Example |
|-------|------|---------|
| condition | enum | "used" |
| condition_confidence | number | 0.85 |
| color | array | ["red", "black"] |
| material | enum | "plastic" |
| material_confidence | number | 0.92 |
| size_category | enum | "small" |
| category | enum | "Electronics" |
| subcategory | string | "Gaming Controllers" |
| notable_features | array | ["PlayStation logo", "USB-C port"] |

### **Layer 2b: Product Identification (SerpAPI + Claude Haiku 4.5)**

Fields populated by parsing SerpAPI Google Lens results:

| Field | Type | Source | Example |
|-------|------|--------|---------|
| brand | string | SerpAPI title parsing | "Sony" |
| model | string | SerpAPI title parsing | "WH-1000XM5" |
| variant | string | SerpAPI title parsing | "Black" |
| estimated_value | number | SerpAPI price averaging | 399.99 |
| product_url | string | SerpAPI link | "https://www.amazon.com/..." |
| name | string | SerpAPI title | "Sony WH-1000XM5 - Black" |

**Parsing Logic (Claude Haiku 4.5):**

The Haiku model receives the SerpAPI JSON response and extracts structured fields using pattern matching:

```json
{
  "visual_matches": [
    {
      "title": "Sony WH-1000XM5 Wireless Noise Cancelling Headphones - Black",
      "link": "https://www.amazon.com/...",
      "source": "Amazon",
      "price": { "value": "$399.99" }
    }
  ]
}
```

Haiku extracts:
- **brand**: First capitalized word/known brand name ("Sony")
- **model**: Model identifier following brand ("WH-1000XM5")
- **variant**: Color/storage/generation suffix ("Black")
- **estimated_value**: Average price across top 5 matches ($399.99)
- **product_url**: Most reliable source (prioritizes Amazon/Best Buy/Target)

### **Layer 3: AI Reasoning (Claude Sonnet 4.5)**

Fields populated by cross-validation and reasoning:

| Field | Type | Description |
|-------|------|-------------|
| confidence | number | Overall confidence score (0.0-1.0) |
| source | enum | Data provenance classification |
| action | enum | Recommended action (save/request_photos/etc) |
| reasoning | string | Natural language explanation |

**Reasoning Logic:**

Claude Sonnet 4.5 receives all data from Layers 1, 2a, and 2b, then:
1. Cross-validates vision attributes against SerpAPI results
2. Resolves conflicts (e.g., vision says "red" but SerpAPI says "Cosmic Red")
3. Calculates confidence score based on agreement
4. Determines appropriate action based on confidence thresholds

## Field-Level Details

### **Source Provenance**

| Value | Meaning | Example Scenario |
|-------|---------|------------------|
| `barcode_validated` | **NEW (ADR-018)**: Barcode scan provided authoritative product ID, vision supplements condition/context | Heinz Ketchup: EAN-13 barcode → UPC Database API → Product name/brand. Vision analysis adds "used, 80% full" |
| `serpapi_validated` | SerpAPI returned high-confidence match, validated by vision analysis | Sony DualSense controller: Vision sees "PlayStation logo" + SerpAPI returns "DualSense" match |
| `vision_only` | No SerpAPI match, metadata from vision analysis only | Handmade ceramic mug: Not in product database, vision extracts color/material |
| `hybrid` | Metadata combined from both sources (neither fully confident) | Generic scissors: Vision identifies "metal blades", SerpAPI suggests "Fiskars" with medium confidence |
| `vision_only_fallback` | SerpAPI API failed, temporary fallback to vision | API outage: Vision provides attributes, scheduled for retry in 6 hours |
| `on_device_only` | Free tier user, no cloud enrichment | Basic label "scissors" from iOS Vision Framework |

### **Action Types**

| Value | Meaning | Next Step |
|-------|---------|-----------|
| `save` | High confidence, save metadata as-is | Write to Firestore, display to user |
| `request_additional_photos` | Low confidence, need more info | Notify user with specific request ("Close-up of barcode needed") |
| `manual_review` | Conflicting data, requires human judgment | Flag for customer support review |
| `save_and_retry_later` | SerpAPI failed, using vision fallback | Save current metadata, schedule Cloud Scheduler retry in 6 hours |

### **Confidence Scoring**

**Overall Confidence (0.0-1.0):**

- **0.90-1.00:** High confidence, validated match
- **0.75-0.89:** Good confidence, likely accurate
- **0.60-0.74:** Medium confidence, may need validation
- **0.00-0.59:** Low confidence, additional photos recommended

**How Confidence is Calculated (AI Reasoning Layer):**

```
confidence = weighted_average([
  serpapi_match_score * 0.50,
  vision_material_confidence * 0.15,
  vision_condition_confidence * 0.15,
  attribute_match_score * 0.20
])

attribute_match_score = similarity(vision_color, serpapi_color)
                      + similarity(vision_category, serpapi_category)
```

## Validation Rules

**TypeScript Schema Validation:**

```typescript
import Ajv from 'ajv';
import enrichedItemSchema from './enriched-item-metadata.schema.json';

const ajv = new Ajv();
const validate = ajv.compile(enrichedItemSchema);

function validateMetadata(metadata: unknown): EnrichedItemMetadata {
  if (!validate(metadata)) {
    throw new Error(`Invalid metadata: ${JSON.stringify(validate.errors)}`);
  }
  return metadata as EnrichedItemMetadata;
}
```

**Business Logic Validation:**

```typescript
function validateBusinessRules(metadata: EnrichedItemMetadata): void {
  // Rule 1: If action = "save", confidence must be > 0.60
  if (metadata.action === 'save' && metadata.confidence < 0.60) {
    throw new Error('Cannot save item with confidence < 0.60');
  }

  // Rule 2: If source = "serpapi_validated", product_url must exist
  if (metadata.source === 'serpapi_validated' && !metadata.product_url) {
    throw new Error('SerpAPI validated items require product_url');
  }

  // Rule 3: If tier = "free", source must be "on_device_only"
  if (metadata.tier === 'free' && metadata.source !== 'on_device_only') {
    throw new Error('Free tier items cannot have cloud enrichment');
  }

  // Rule 4: estimated_value must be null or positive
  if (metadata.estimated_value !== null && metadata.estimated_value < 0) {
    throw new Error('estimated_value cannot be negative');
  }
}
```
