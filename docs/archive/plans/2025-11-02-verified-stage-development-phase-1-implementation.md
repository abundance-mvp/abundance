# Apple Docs Fetcher

Fetches comprehensive Apple Developer documentation via Sosumi.ai (clean markdown conversion) and saves locally for fast reference during iOS stage development.

**When to use:** Once before running any iOS stages (2.2, 3.1, 4.1), or to refresh stale docs (>30 days).

**Invocation:** `/apple-docs-fetcher` or `/apple-docs-fetcher --refresh`

---

## Process

### Step 1: Analyze Project Scope

Read the following to identify ALL Apple technologies needed:
- `docs/abundance-analysis-pipeline-design.md` (identify iOS stages: 2.2, 3.1, 4.1)
- All files in `docs/specs/PRD-*.md` (extract iOS features)

Build technology list based on features:
- AI Cataloging → Vision, Visual Intelligence, AVFoundation
- UI/UX → SwiftUI, Liquid Glass (iOS 26)
- Payment → StoreKit, Apple Pay
- Auth → Sign in with Apple, Keychain
- Storage → Core Data, CloudKit
- Security → Secure Enclave, Data Protection
- Base → Swift 6.x language docs

### Step 2: Check if Refresh Needed

If `docs/apple/` exists:
- Read manifests to check fetch dates
- If all < 30 days and not `--refresh` flag: Skip fetching, inform user
- If any >= 30 days or `--refresh` flag: Proceed with refresh

### Step 3: Fetch Documentation

For each technology:

1. **Identify key documentation URLs** from developer.apple.com
   - Example: https://developer.apple.com/documentation/swiftui
   - Example: https://developer.apple.com/documentation/vision

2. **Convert to Sosumi.ai URLs**
   - Replace: `developer.apple.com` → `sosumi.ai`
   - Example: https://sosumi.ai/documentation/swiftui

3. **Fetch using WebFetch tool**
   ```
   WebFetch:
     url: https://sosumi.ai/documentation/swiftui/views
     prompt: "Extract the complete documentation in markdown format. Return the full text."
   ```

4. **Save to local structure**
   - File: `docs/apple/{technology}/{doc-name}.md`
   - Example: `docs/apple/swiftui/views-and-controls.md`

5. **Update manifest**
   - File: `docs/apple/{technology}/manifest.json`
   - Format:
   ```json
   {
     "technology": "swiftui",
     "fetched_date": "2025-11-02",
     "fetch_source": "sosumi.ai",
     "docs": [
       {
         "title": "SwiftUI Views and Controls",
         "original_url": "https://developer.apple.com/documentation/swiftui/views",
         "sosumi_url": "https://sosumi.ai/documentation/swiftui/views",
         "local_path": "views-and-controls.md",
         "fetch_date": "2025-11-02",
         "size_kb": 124
       }
     ]
   }
   ```

### Step 4: Create Directory Structure

Create directories:
```bash
mkdir -p docs/apple/{swift,swiftui,liquid-glass,vision,visual-intelligence,payment,auth,storage,camera,security}
```

- ✅ Cost savings (no repeated web fetches)
