# Link Presentation Framework Overview
**Source**: https://sosumi.ai/documentation/linkpresentation
**Fetched**: 2025-11-02
## Overview
Link Presentation enables developers to display rich link previews with metadata.
## Components
- **LPMetadataProvider**: Fetches link information asynchronously
- **LPLinkMetadata**: Provides access to URLs, titles, icons, images, and media
- **LPLinkView**: Renders interactive link previews
## Error Handling
Specific error conditions include metadataFetchCancelled, metadataFetchFailed, metadataFetchTimedOut, and metadataFetchNotAllowed.
