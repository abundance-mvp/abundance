# Observation Framework Overview
**Source**: https://sosumi.ai/documentation/observation
**Fetched**: 2025-11-02
## Overview
The Observation framework provides Swift with declarative change tracking capabilities for model objects.
## Core Components
- **@Observable macro**: Automatically synthesizes observation capabilities
- **Observable protocol**: Defines the interface for observable types
- **withObservationTracking()**: Executes code while monitoring property access
- **ObservationRegistrar**: Manages observation subscriptions and change notifications
## SwiftUI Integration
The framework integrates seamlessly with SwiftUI for managing model data.
