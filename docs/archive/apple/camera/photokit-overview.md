**Source**: https://sosumi.ai/documentation/photokit

## Overview
PhotoKit is Apple's framework collection for photo and video management in iOS applications.

## Core Frameworks

Two primary frameworks comprise PhotoKit:

1. **Photos** - Handles photo library access and asset management
2. **PhotosUI** - Provides user interface components for photo selection and interaction
