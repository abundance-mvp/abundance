# Foundation Framework Overview
**Source**: https://sosumi.ai/documentation/foundation
**Fetched**: 2025-11-02
## Overview
The Apple Foundation framework provides essential data types and utilities for Swift development including fundamental numeric types, binary data handling, and formatting capabilities.
## Core Data Types
- **Decimal**: Value type for precise decimal arithmetic
- **Data**: Manages byte sequences with file I/O, Base-64 encoding/decoding
## Arithmetic Operations
Decimal supports comprehensive mathematical operations with customizable rounding modes including plain, down, up, and bankers rounding.
## Formatting and Parsing
Decimal formatting supports locale-aware number formatting, currency styles, percentage formatting, precision control, and notation options.
