# Accelerate Framework Overview
**Source**: https://sosumi.ai/documentation/accelerate
**Fetched**: 2025-11-02
## Overview
Accelerate framework provides neural network capabilities through BNNS (Basic Neural Network Subroutines) library.
## Neural Network Layers
Extensive layer implementations including activation layers, convolutional layers, fully connected layers, normalization layers, pooling operations, and loss functions.
## Graph Compilation and Execution
Compile graph objects from files and manage execution contexts, including dynamic shape configuration and batch size management.
## Advanced Features
Fused layer operations, sparse matrix support, optimization preferences, custom memory allocation callbacks, and message logging.
