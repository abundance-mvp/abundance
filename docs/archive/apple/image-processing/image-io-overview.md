# Image I/O Framework Overview
**Source**: https://sosumi.ai/documentation/imageio
**Fetched**: 2025-11-02
## Overview
Image I/O provides comprehensive capabilities for reading, writing, and manipulating image data across multiple formats.
## Core Features
- **Image Reading**: Create sources from URLs, data, or providers; extract images and thumbnails
- **Image Writing**: Create destinations for files, data, or custom consumers
- **Metadata Management**: XMP metadata processing with tag operations
- **Animation Support**: Functions for animated format handling
- **Supported Formats**: JPEG, PNG, GIF, TIFF, HEIC, WebP (read/write); DNG, CRW/CR2, NEF, RAF (read-only)
