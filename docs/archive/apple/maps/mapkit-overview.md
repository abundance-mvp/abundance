# MapKit Framework Overview
**Source**: https://sosumi.ai/documentation/mapkit
**Fetched**: 2025-11-02
## Overview
MapKit is Apple's framework for embedding maps, displaying location-based information, and providing navigation capabilities in iOS and macOS applications.
## Core Components
- **MKMapView**: Interactive mapping with standard, satellite, hybrid, and flyover map types
- **Annotations**: Point annotations, marker views, cluster annotations, and user location
- **Overlays**: Polygons, polylines, circles, and tile overlays
- **Directions & Routing**: Calculate routes for driving, walking, cycling, transit
- **Local Search**: Discover nearby POIs and addresses
- **Street-Level Viewing**: MKLookAroundViewController for immersive street imagery
