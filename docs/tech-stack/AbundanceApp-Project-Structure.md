## Overview

This document defines the complete directory structure for the Abundance iOS project. The project uses Swift Package Manager (SPM) for modular architecture with local packages organized into Features, Core, and Shared layers per ADR-011.

**Key Design Principles**:
1. **Modular**: Each feature is an independent Swift package with its own Package.swift
2. **Testable**: All modules include test targets (unit tests for ViewModels, integration tests for repositories)
3. **Scalable**: New features can be added without modifying existing modules
4. **Clear Dependencies**: Dependency graph flows downward (Features → Core → Shared)

## Root Directory Structure

```
Abundance/
├── Abundance.xcodeproj/          # Xcode project file
├── Abundance.xcworkspace/        # Workspace (if using CocoaPods fallback)
├── App/                          # Main app target (SwiftUI App, entry point)
├── Packages/                     # Local Swift packages (modular architecture)
│   ├── Features/                 # Feature modules (UI + business logic)
│   ├── Core/                     # Core services (networking, Firebase, Vision)
│   └── Shared/                   # Shared utilities (components, extensions)
├── Tests/                        # App-level integration and UI tests
├── .swiftlint.yml                # SwiftLint configuration
├── Sourcery.yml                  # Sourcery code generation configuration
├── .gitignore                    # Git ignore rules
├── README.md                     # Project README
└── Generated/                    # Sourcery generated code (mocks)
```

## App Target (`App/`)

**Purpose**: Main application target, entry point for iOS app.

### Directory Structure

```
App/
├── AbundanceApp.swift            # @main SwiftUI App entry point
├── ContentView.swift             # Root view (tab bar or navigation container)
├── Assets.xcassets/              # App icons, colors, images
├── Preview Content/              # SwiftUI preview assets
├── Info.plist                    # App configuration (camera permissions, Firebase)
├── GoogleService-Info.plist      # Firebase configuration (DO NOT COMMIT)
└── Localizable.strings           # Localization strings (optional for Phase 1)
```

### Key Files

**`AbundanceApp.swift`** (Entry Point):
```swift
import SwiftUI
@preconcurrency import FirebaseCore

@main
struct AbundanceApp: App {
    init() {
        // Firebase initialization
        FirebaseApp.configure()
    }

    var body: some Scene {
        WindowGroup {
            ContentView()
        }
    }
}
```

**`ContentView.swift`** (Root View):
```swift
import SwiftUI
import CatalogFeature
import CameraFeature
import ProfileFeature

struct ContentView: View {
    var body: some View {
        TabView {
            CatalogView()
                .tabItem {
                    Label("Catalog", systemImage: "square.grid.2x2")
                }

            CameraView()
                .tabItem {
                    Label("Camera", systemImage: "camera")
                }

            ProfileView()
                .tabItem {
                    Label("Profile", systemImage: "person.circle")
                }
        }
    }
}
```

**Purpose**: App-level integration tests and UI tests (XCTest, XCUITest).

```

│   ├── CatalogIntegrationTests.swift
│   └── AuthIntegrationTests.swift

    ├── OnboardingUITests.swift
```

**Test Types**:
- **Unit Tests**: In each module's `Tests/` directory (ViewModels, repositories)
- **Integration Tests**: In `Tests/AbundanceIntegrationTests/` (Firestore, Firebase Emulator)
- **UI Tests**: In `Tests/AbundanceUITests/` (XCUITest, critical user flows)

## Dependency Graph

**Allowed Dependencies** (downward only):
```
App
 ├─→ Features (CatalogFeature, CameraFeature, OnboardingFeature, ProfileFeature)
      ├─→ Core (Models, Networking, Firebase, Vision, Persistence)
      │    └─→ Shared (Components, Extensions, Constants)
      └─→ Shared
```

**Rules**:
1. ✅ Features can depend on Core and Shared
2. ✅ Core can depend on Shared
3. ❌ Features NEVER depend on other Features (avoid circular dependencies)
4. ❌ Core NEVER depends on Features
5. ❌ Shared NEVER depends on Features or Core

## File Naming Conventions

### Swift Files
- **Views**: `{Name}View.swift` (e.g., `CatalogView.swift`, `ItemCard.swift`)
- **ViewModels**: `{Name}ViewModel.swift` (e.g., `CatalogViewModel.swift`)
- **Models**: `{Name}.swift` (e.g., `CatalogItem.swift`, `User.swift`)
- **Protocols**: `{Name}Protocol.swift` or `{Name}.swift` (e.g., `CatalogRepository.swift`)
- **Services**: `{Name}Service.swift` (e.g., `VisionService.swift`, `FirebaseStorageService.swift`)
- **Extensions**: `{Type}+{Category}.swift` (e.g., `Date+Extensions.swift`, `View+Extensions.swift`)

### Test Files
- **Unit Tests**: `{Name}Tests.swift` (e.g., `CatalogViewModelTests.swift`)
- **Integration Tests**: `{Feature}IntegrationTests.swift` (e.g., `CatalogIntegrationTests.swift`)
- **UI Tests**: `{Feature}UITests.swift` (e.g., `CameraFlowUITests.swift`)

### Capitalization
- **Types** (classes, structs, protocols): `PascalCase` (e.g., `CatalogViewModel`, `CatalogItem`)
- **Files**: Match type name (e.g., `CatalogViewModel.swift`)
- **Directories**: `PascalCase` (e.g., `ViewModels/`, `Repositories/`)

## Build Targets

### Main App Target
- **Name**: Abundance
- **Type**: iOS App
- **Dependencies**: All feature modules
- **Minimum iOS Version**: 26.0

### Feature Module Targets
- **Names**: CatalogFeature, CameraFeature, OnboardingFeature, ProfileFeature
- **Type**: Dynamic Library (`.library`)
- **Dependencies**: Core + Shared modules

### Core Module Targets
- **Names**: Models, Networking, FirebaseIntegration, VisionProcessing, Persistence
- **Type**: Dynamic Library
- **Dependencies**: Shared modules (and external SPM packages like Firebase)

### Shared Module Targets
- **Names**: Components, Extensions, Constants
- **Type**: Dynamic Library
- **Dependencies**: None (foundation only)

## Getting Started

### Prerequisites
- macOS 15.0+ (Sequoia)
- Xcode 16.2+ (Swift 6.0 compiler)
- SwiftLint 0.62.2+ (`brew install swiftlint`)
- Sourcery 2.3.0+ (`brew install sourcery`)

### Initial Setup
1. Clone repository
2. Open `Abundance.xcodeproj` in Xcode
3. Add `GoogleService-Info.plist` to `App/` directory (download from Firebase Console)
4. Run `sourcery --config Sourcery.yml` to generate mocks
5. Select iPhone 16 Pro simulator (iOS 26)
6. Press Cmd+R to build and run
