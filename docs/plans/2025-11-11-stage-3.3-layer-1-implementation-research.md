### Task 4: Create Accuracy Benchmarking Methodology

**Objective**: Define how to measure Layer 1 accuracy on household items.

**Subtasks**:

4.1. **Create test dataset specification**:
- 50-100 household item photos (camping gear, kitchen items, electronics)
- Ground truth labels (manual annotation)
- Varied conditions: well-lit, low-light, cluttered background, multiple items

4.2. **Define accuracy metrics**:
- Precision: TP / (TP + FP) - how many detections are correct?
- Recall: TP / (TP + FN) - how many actual items were detected?
- F1 Score: 2 * (Precision * Recall) / (Precision + Recall)
- IoU (Intersection over Union): Bounding box accuracy
- mAP (mean Average Precision): Overall detection quality

4.3. **Create benchmarking script**:
```swift
struct BenchmarkResult {
    let precision: Float
    let recall: Float
    let f1Score: Float
    let meanIoU: Float
    let mAP: Float
    let latency: TimeInterval
}

func benchmarkDetector(
    detector: HouseholdItemDetector,
    testDataset: [TestImage]
) async throws -> BenchmarkResult
```

4.4. **Document baseline accuracy targets**:
- YOLOv3-Tiny COCO mAP: 33.1% (from ADR-013)
- Target household item mAP: >40% (with class filtering)
- Target precision: >70%
- Target recall: >60%

### Task 5: Document Edge Case Handling Patterns

**Objective**: Create implementation patterns for common household item detection edge cases.

**Subtasks**:

5.1. **Low light detection and mitigation**:
- Detect low light: Calculate image brightness (average pixel luminance)
- Mitigation: Boost exposure, apply histogram equalization, adjust confidence threshold
- User feedback: "Image is too dark. Try using flash or better lighting."

5.2. **Motion blur detection and mitigation**:
- Detect blur: Calculate Laplacian variance (edge sharpness)
- Mitigation: Prompt user to retake photo with steady hand
- User feedback: "Image is blurry. Hold camera steady and retake."

5.3. **Overlapping object resolution**:
- Detect overlaps: Calculate IoU between bounding boxes
- Resolution: Use Non-Maximum Suppression (NMS) to remove duplicates
- Keep highest confidence detection per cluster

5.4. **No objects detected handling**:
- Possible causes: Wrong camera angle, out of focus, no household items in frame
- User feedback: "No items detected. Try taking photo from different angle."
- Fallback: Allow manual item creation

5.5. **Too many objects detected (>10)**:
- Possible causes: Cluttered scene, low confidence threshold
- Resolution: Show top 10 by confidence, allow pagination
- User feedback: "Multiple items detected. Review each item below."

**Acceptance Criteria**:
- [x] Low light detection and mitigation implemented
- [x] Motion blur detection and mitigation implemented
- [x] Overlapping object resolution with NMS
- [x] No objects detected handling with user feedback
- [x] Too many objects handling with pagination

### Risks

#### Risk 1: YOLOv3-Tiny Accuracy Lower Than Expected on Household Items

- **Impact**: High (core value proposition at risk if accuracy <40%)
- **Probability**: Medium (COCO dataset not optimized for household items)
- **Mitigation**:
  - Create household item test dataset (Task 4)
  - Benchmark actual accuracy vs target (BENCHMARK-001)
  - Document accuracy in research report (RESEARCH-003)
  - If <40% mAP: Consider fine-tuning model in Stage 4.3

#### Risk 2: Performance Degrades with Edge Case Handlers

- **Impact**: Medium (300-500ms latency target may be missed)
- **Probability**: Medium (brightness checks, blur detection add overhead)
- **Mitigation**:
  - Benchmark each edge case handler separately (Task 3)
  - Run edge case checks in parallel with detection
  - Document performance impact in DESIGN-039

#### Risk 3: Test Dataset Creation Requires Manual Labor

- **Impact**: Low (time-consuming but not blocking)
- **Probability**: High (50-100 images need manual ground truth labels)
- **Mitigation**:
  - Start with 20 images for MVP benchmarking
  - Expand to 50-100 images in Stage 4.3 if needed
  - Use existing camping gear photos from user research
