## Verified Technical Constraints

### Swift 6 Strict Concurrency (CRITICAL)

**Syntax**: `.enableUpcomingFeature("StrictConcurrency")`
**Source**: RESEARCH-VALIDATION-stage-4.1.md, Claim 6
**Rationale**: Swift 6.0 renamed `.enableExperimentalFeature` → `.enableUpcomingFeature`

### iOS 26 Platform Declaration

**Syntax**: `.iOS(.v26)` or `.iOS("26.0")` (fallback if enum unavailable)
**Source**: RESEARCH-VALIDATION-stage-4.1.md, Claim 1
**Verification**: PackageDescription 6.2+ required

### Firebase Workaround

**Pattern**: `@preconcurrency import FirebaseAuth`
**Source**: RESEARCH-VALIDATION-stage-4.1.md, Claim 10; CODE-EXAMPLE-003
**Rationale**: Firebase iOS SDK 11.x partial Swift 6 support (full support Q1 2026)

## Dependencies & Risks

### External Dependencies

| Dependency | Type | Mitigation |
|------------|------|------------|
| iOS 26 availability | Hard requirement | ✅ VERIFIED: Released Sept 15, 2025 (RESEARCH-VALIDATION-stage-4.1.md) |
| Swift 6.0 compiler | Hard requirement | ✅ VERIFIED: Ships with Xcode 16.2+ |
| Firebase iOS SDK 11.11.0+ | Hard requirement | ✅ VERIFIED: Exists on GitHub, async/await supported |
| SwiftLint 0.62.2+ | Soft dependency | ⚠️ Can fallback to 0.55.0 if needed (less Swift 6 support) |
| Sourcery 2.3.0+ | Soft dependency | ⚠️ Can skip if code generation not critical for scaffolding |

### Technical Risks

**Risk 1: Swift 6 Strict Concurrency Build Failures**
- **Probability**: Medium (30%)
- **Impact**: High (blocks development)
- **Mitigation**: All Package.swift files use verified syntax (`.enableUpcomingFeature("StrictConcurrency")`)
- **Contingency**: Provide fallback without strict concurrency if blocking

**Risk 2: Firebase @preconcurrency Workaround**
- **Probability**: Low (10%)
- **Impact**: Medium (warnings in build log)
- **Mitigation**: All Firebase imports use `@preconcurrency` pattern from CODE-EXAMPLE-003
- **Timeline**: Full Swift 6 support expected Q1 2026 (can remove workaround then)

**Risk 3: iOS 26 Platform Enum Unavailable**
- **Probability**: Low (15%)
- **Impact**: Low (fallback available)
- **Mitigation**: Use string literal `.iOS("26.0")` if `.iOS(.v26)` enum unavailable
- **Test**: Verify PackageDescription version 6.2+ includes .v26 enum

**Risk 4: Tool Version Mismatches**
- **Probability**: Medium (25%)
- **Impact**: Medium (linting/codegen failures)
- **Mitigation**: README includes exact tool versions and Homebrew install commands
- **Recovery**: Document workarounds for older tool versions in troubleshooting section
