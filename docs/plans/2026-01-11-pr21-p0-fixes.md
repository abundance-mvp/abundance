**Files:**

**Step 1: Read current implementation**

The `photoContinuation` property is `nonisolated(unsafe)` and accessed from multiple queues without synchronization.

**Step 2: Add NSLock for synchronization**

```swift
// Add property after line 27:
private let continuationLock = NSLock()

// Modify capturePhoto() around line 90:
public func capturePhoto() async throws -> Data {
    return try await withCheckedThrowingContinuation { continuation in
        sessionQueue.async { [weak self] in
            guard let self = self else {
                continuation.resume(throwing: CameraError.deviceNotAvailable)
                return
            }

            // ADDED: Lock before accessing photoContinuation
            self.continuationLock.lock()
            defer { self.continuationLock.unlock() }

            // Check if capture already in progress
            if self.photoContinuation != nil {
                continuation.resume(throwing: CameraError.captureInProgress)
                return
            }

            guard self.captureSession.isRunning else {
                continuation.resume(throwing: CameraError.captureFailure)
                return
            }

            self.photoContinuation = continuation
            // ... rest of capture logic
        }
    }
}

// Modify delegate callback around line 185:
public func photoOutput(_ output: AVCapturePhotoOutput, didFinishProcessingPhoto photo: AVCapturePhoto, error: Error?) {
    continuationLock.lock()
    let continuation = photoContinuation
    photoContinuation = nil
    continuationLock.unlock()

    // Now safely use continuation outside lock
    if let error = error {
        continuation?.resume(throwing: CameraError.captureFailure)
        return
    }
    // ... rest of processing
}
```

**Files:**

**Apple Docs Verification Required:**
```
Invoke apple-docs-fetcher with: "CVPixelBuffer"
Invoke apple-docs-fetcher with: "Swift unchecked Sendable"
```

**Step 1: Enhance documentation with safety invariants**

```swift
/// CVPixelBuffer Sendable conformance for Swift 6 concurrency.
///
/// # Safety Requirements (MUST be maintained)
///
/// This conformance is safe ONLY if:
/// 1. All VisionCore operations use `CVPixelBufferLockBaseAddress` with `.readOnly` flag
/// 2. No code retains references to the pixel buffer's base address across await points
/// 3. The buffer is not modified after being passed across isolation boundaries
///
/// # Verification Checklist
///
/// Before adding new CVPixelBuffer operations, verify:
/// - [ ] Uses `.readOnly` lock flag
/// - [ ] Does not store base address pointer
/// - [ ] Completes before returning/awaiting
///
/// # Why @unchecked?
///
/// CVPixelBuffer is a Core Foundation type without Sendable conformance.
/// Vision Framework operations are read-only by design, making this safe
/// for our use case. The compiler cannot verify CF type thread safety.
///
/// - Warning: Violations of these invariants will cause data races.
///   Any code that writes to CVPixelBuffer MUST NOT pass it across isolation boundaries.
extension CVPixelBuffer: @unchecked @retroactive Sendable {}
```

**Step 2: Commit**

### Task 6: Sanitize User IDs in AppLogger

```swift
// Add after line 60 (inside LogEvent enum):
/// Sanitizes user IDs for logging to prevent PII exposure.
/// Shows first 4 chars + hash suffix for correlation without full exposure.
private static func sanitizeUserId(_ userId: String) -> String {
    guard userId.count > 4 else {
        return String(repeating: "*", count: userId.count)
    }
    let prefix = String(userId.prefix(4))
    let hash = String(abs(userId.hashValue) % 1000000)
    return "\(prefix)***\(hash)"
}
```

**Step 2: Update message formatting**
